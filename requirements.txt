# This was a full `pip freeze`: 77 pinned packages, most of them transitive and
# several — groq, langchain-groq, sqlalchemy, numpy, lxml — pulled in by
# langchain-community and never imported by this project. Pinning the whole
# tree meant every transitive CVE became a manual bump here, which is how
# langsmith, pyasn1 and pydantic-settings ended up shipping with known
# advisories.
#
# Lower bounds, not exact pins: pip resolves compatible transitives, and
# security fixes arrive without editing this file. Pin exactly only if a
# reproducible build is needed, and use a lockfile for that.
